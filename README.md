# NASA Space Fact of the Day

## Project Idea
A simple web page that shows a random space fact each time you click a button. It helps NASA's mission of inspiring and educating the public by making space knowledge quick, fun and easy to access, especially for students.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub for version control and project management

## How to Run
1. Clone this repository:
   `git clone https://github.com/sfd502/nasa-space-fact-of-the-day.git`
2. Open the project folder.
3. Double-click `index.html` to open it in your web browser.
4. Click the "New Fact" button to see a random space fact.
